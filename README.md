# TeacherHubPro

AI workspace for teachers, schools and homeschool families: lesson planning, classes, attendance, gradebook and report cards, assignments with AI grading, educational and live games, adaptive learning, parent portals and a weekly lesson-prep agent. Spanish and English.

This is a clean rebuild of the original app, built step by step with Claude Code.

- `CLAUDE.md` — rules for every Claude Code session
- `docs/BUILD_STEPS.md` — the build plan, one step at a time
- `docs/FEATURES.md` — everything the original app does, by build step
